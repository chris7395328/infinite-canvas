腾讯VOD国际站 WAND-Vega 接入

1. 同时更新app、proxy到本次镜像；保持现有task-data目录映射不变。
2. 配置 → 腾讯VOD → 添加腾讯VOD海外渠道。四个版本已附带调用脚本。
3. 在该页填写SecretId、SecretKey、SubAppId，不需要Bearer API Key。
4. 从已有渠道复制COS，确认Bucket／Endpoint／公网基址／COS Secret均为你已有的可用配置。复制不改动来源渠道，不把VOD密钥当COS密钥。
5. 启用本地代理；Docker使用同域/canvas-proxy。在画布选择1.0-pro、1.0-pro-fast、1.0-pro-mini或1.5-pro，按节点连入图片、视频、音频并提交。

独立脚本源码：web/src/services/api/tencent-vod-script.js（异步函数体，整体复制到模型调用脚本编辑器，不直接作为普通JS模块运行）。
脚本读取当前模型版本及渠道配置；不在脚本里填写密钥。清空脚本也可使用同一VOD默认适配。
请求由Docker构造并签名：1.5-pro仅在有素材且不是首帧／首尾帧模式时发送omni_reference_task_type；纯文字或首帧／首尾帧不发送该字段。此修复需要新版proxy，仅替换脚本不能修复旧代理；不自动重跑旧失败任务。

API固定国际站https://vod.intl.tencentcloudapi.com/，ModelName=wand-vega-video，所选模型名作为ModelVersion。文档没有/models，不调用列表接口。
素材流程：本地节点 → 现有COS URL → 当前VOD应用素材库 → asset:// → 视频生成。国际站按接入文档传IsRealPerson="False"，不调用国内站活体认证。素材必须有合法使用权，仍受审核。旧火山/Pixmax的asset ID不能跨应用使用。
默认入库，可在VOD设置关闭；直接URL包含人像时可能被拒绝。共享SubAppId的权限、费用与资源归属需向提供方确认。

文档范围：1.0-pro 4-15秒、1.5-pro 4-30秒，支持-1自动时长。分辨率界面按通用表列出720P/1080P/2K/4K，fast/mini具体权限由上游判断，不保证所有档位可用。1.5-pro支持参考/自动/编辑/延长；编辑需视频并使用adaptive和-1时长，延长需视频且adaptive。首尾帧只用1-2张图，不与其他素材混用。
无文档依据的草稿、固定镜头和MOV生成选项不开放。返回尾帧可请求，但当前画布只保存视频，不自动另建尾帧图片节点。完整引用素材的时长/尺寸/格式以所给文档及实际响应为准。

后台每10秒重新签名查询同一任务，不因网络查询失败重新创建；完成视频存入映射目录，24小时后清理，领取不提前删除。不会持久化请求体、SecretKey或鉴权头。关闭网页不停止已经接收的任务；素材读取/提交前关闭不保证已受理。重启容器会切断运行中任务，保留已收到的任务ID并提示不确定，不自动重发；请在更新前等待现有生成完成。
费用沿用提交参数快照，不读成片时长；自动时长按秒无法估算。真实VOD权限、费用、素材入库及生成效果需你使用自己的账号验收，本次只进行本地模拟测试。

安全：配置导出文件含密钥，请勿公开。不要公开无访问控制的canvas-proxy；优先HTTPS和反向代理认证/内网访问。
