## 使用

1. 本机：先等现有生成结束，用「停止本机画布」停止后台，再双击「启动本机画布」，按提示让当前源码重新构建，刷新网页。Docker：同一源码已兼顾，但旧镜像不含此次改动，需要用户另行明确要求后才构建／发布。不能只把新脚本贴到旧代理；脚本会在生成前检查任务ID回执能力，缺失时停止。
2. 保留原渠道的 Base URL、Key、OpenAI 格式和在线模型列表。找到视频模型 `doubao-seedance-2-5-260628`，仅编辑它的「调用脚本」。选模板 **Seedance 2.5 平台素材库／草稿（JSON协议）**，或完整复制源码 `web/src/services/api/seedance25-assets-script.js` 后保存。第一行 `@canvas-video-profile` 标记必须保留；它显式启用草稿界面，不按域名自动分流，不影响2.0、933或其他脚本。
3. 草稿开关启用后固定480p。生成成功会保存**平台**草稿任务ID，显示原有“生成正式视频”按钮。点击该按钮新建1080p任务，`content` 只有一个 `draft_task`，不再读图、上传、注册素材或重发提示词／时长／比例／音轨／Seed。普通“生成”仍是独立的新预览，不隐式转正式。
4. 当前价格仍由你在模型里设置的480p、720p、1080p分档及秒数／次数估算；素材上传／登记不计为生成，只有视频创建POST预记费，领取保存后确认。自动时长不能按秒估算。平台 `/v1/videos/{id}/billing` 是实际账单入口，未把它冒充当前费用估算，也未擅自填价格。

## 图片、视频和音频

流程为 **画布本地素材 → 已有新加坡COS → 本平台CreateAsset → GetAsset为Active → asset://引用**。

`uploadToCos` 优先当前渠道的完整COS配置；缺失时仅在当前浏览器已配置的COS中找到唯一一套凭据才复用，相同Bucket／Endpoint／凭据的多份配置视为同一套。你的既有公网基址是 `https://sg-cos.maxai.art`；脚本不另建Bucket、不更换账号。多套不同配置时明确报错，可在脚本 `COS_SOURCE_CHANNEL_ID` 填来源渠道ID或为当前渠道绑定COS。COS凭据只发给自己的 `/seedance/cos-upload`，不会传给第三方平台。

素材操作走 `POST /v1/video-assets/action?model=当前模型&Action=...&Version=2024-01-01`，只用该平台的Bearer Key，无需使用官方私域库AK/SK。素材JSON不重复塞model，也不塞Base64。已有本平台asset ID要查询Active；官方或其他渠道的asset ID不能当成已兼容。

按收到的参考数组顺序上传和登记，不去重或重排重复图片，保持图片1、图片2与提示词对应关系。全参考最多30图、10视频、10音频；视频一类总时长≤30秒，音频一类总时长≤30秒，详细规格和审核由平台校验。支持只有音频参考，不能套用其他渠道“必须配图”的限制。首帧／首尾帧只用1～2张图，不混用视频／音频，并使用adaptive。

素材上传／入库阶段仍需保持网页打开；在最终生成POST被本机／Docker后台接收后，关闭网页才可继续等待。刷新不会重跑上传、入库、付费创建；若上传阶段尚未创建视频，不能把它视为已受理的生成任务。

## 真人素材

普通AIGC素材组**不能代替真人认证**。需要认证的人脸图片／视频，必须先在该平台调用 `CreateVisualValidateSession`，由本人打开返回的H5链接完成认证，再用 `GetVisualValidateResult` 取得 `Result.GroupId`。认证凭据不可公开。

把这个GroupId填到脚本顶部 `ASSET_GROUP_ID` 后，再接入真人素材；脚本会使用该组注册并查询素材。留空时只自动创建／缓存普通AIGC组，不伪造认证、不自动退回直接URL绕过审核，也不替用户完成H5。素材组ID缓存按平台地址、模型及Key的本机SHA-256命名，不把Key写入缓存。

## 参数与恢复

- 4～30秒整数或-1自动；普通480p／720p／1080p，草稿固定480p、正式续作固定1080p。编辑／延长必须接视频且adaptive，编辑duration=-1。
- `omni_reference_task_type` 仅对实际全模态参考发送；纯文字、首帧、首尾帧不发送。默认跟随节点选择reference／auto／edit／extend。
- 支持音轨、水印、MP4／MOV；未在此文档公布的固定镜头和Seed不显示、不发送。草稿不发送返回尾帧；普通任务可以请求，但当前画布不会自动另建尾帧图片节点。priority、execution_expires_after、callback_url未增加额外默认值或界面，不擅自延伸文档能力。
- 生成只POST一次，后台每10秒查询同一个平台ID，遵循更长Retry-After，不设置本地6分钟生成超时。文档中的6分钟是平台等待取得上游ID的限制，不是已受理任务的生成时长上限。
- 成片下载不携带平台Key，不猜测 `/content` 下载路径。后台保留视频文件和平台ID，刷新／再次领取直接读已有回执，不运行自定义JS。文件按原规则终态保留24小时、ACK不删除、不续期；素材库和平台草稿的有效期由平台管理，草稿文档期限为7天，超过本地24小时文件保留期不代表本地一定还能重新下载它。
- 本机／容器重启仍会中断运行中后台请求，保留已知任务号并标记不确定，不自动重发；此改动没有实现跨重启自动续查或保证完成所有历史任务。
- 1080p MP4可能是HEVC/H.265和10bit，浏览器不支持解码不等于生成失败。
