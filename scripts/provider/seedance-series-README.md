# Seedance系列平台：编辑、样片与COS参考

依据用户提供的《Seedance系列_客户接入文档(2).md》及用户确认的编辑必填`video_duration`补充约定，平台`http://154.40.44.244:3000`。新协议与旧`video-assets/action + content + draft_task`协议不同，不能仅启用官方火山协议后直接调用。

## 新版文档差异与适配结论

- 四个模型ID、参考字段、编辑`videoEdit2video / 0 / adaptive`、COS HTTPS直链和样片报价接口均未变化；但用户进一步确认编辑还要求`video_duration`（输入视频实际秒数），原脚本漏传。新版补上该字段及中文输入，不改平台素材上传或官方私域库。旧版脚本须明确替换，不能继续沿用缺字段的编辑请求。
- 平台新增明确验收边界：只实测2.5无素材5秒720p16:9生成、查询，以及已修复的完整／Range鉴权下载。其他三款、参考素材、编辑、上传和样片转正片尚未完整客户验收；管理员账号测试不等于你的分组和令牌均已开通。这里只记录对方文档声明，不是本项目已替你完成线上验收。
- 平台API继续使用原HTTP地址和端口，`/v1`只拼一次；素材直链仍须公网HTTPS。当前默认脚本和URL拼接已符合。Python示例30分钟停止等待不是平台生成时限，不替换本项目已确认的后台持续等待／10秒查询策略。
- 客户文档建议只在服务端保存平台Key；画布当前仍把渠道Key保存在浏览器本地并转交自己的代理，本轮没有改成服务端密钥库，不能宣称满足仅服务端存钥要求。平台这一跳是HTTP明文，使用限额专用令牌并避免敏感素材。
- 新文档强调读取`error.code`与`error.message`；未给具体原因时不推断参数、审核或余额。代理现复用统一错误解析保留code／message／Request ID，Seedance系列附平台公共任务ID，失败回执跨重启保留；不伪造内部错误、不重跑收费POST。这项后端显示修复需本机重建或更新proxy，不能只换脚本生效；本轮未构建、重启或发布Docker。
- 如改走平台`/v1/assets`上传，只有active可提交，processing／failed不能调用不存在的详情接口反复查询。本模板仍走既有COS，因此不新增上传／轮询动作。普通创建不假设Idempotency-Key保证去重；转正片仍先确认有效报价。

## 接入

1. 保留现有渠道地址、平台Key和OpenAI格式，不改其他渠道。在线模型名以新文档的`seedance-2.0`、`seedance-2.0-fast`、`seedance-2.0-mini`、`seedance-2.5`为准；旧`doubao-…`ID不在本文档范围，不自动改写。
2. 在需要接入的每个模型「调用脚本」里选择 **Seedance系列平台：2.0／2.5编辑／样片报价（COS URL）** 并保存。同一个模板读取当前模型名；完整脚本在`web/src/services/api/seedance-series-script.js`。保留首行`@canvas-video-profile seedance-series`，它负责显式启用对应参数与结果恢复，不按域名推断协议。已保存旧脚本不会自动覆盖；旧模板仍保留为「旧协议」。
3. 本机先等任务结束，停止后用一键启动脚本重建并刷新。Docker使用同一业务源码，但需要新app和proxy；此次未发布镜像。旧后台不支持新版协议时，脚本会在创建前明确阻止，不能只粘贴脚本到旧镜像。

## 模型与节点参数

| 模型 | 分辨率 | 秒数 | 编辑／样片 |
| --- | --- | --- | --- |
| seedance-2.0 | 480p／720p／1080p | 4～15或智能 | 不支持 |
| seedance-2.0-fast、mini | 480p／720p | 4～15或智能 | 不支持 |
| seedance-2.5 | 480p／720p／1080p | 4～30或智能 | 支持 |

复用现有火山视频节点的参数面板，按当前模板及模型显示，不进入官方私域库流程。支持首帧／首尾帧、全参考、音轨和搜索开关。未公布的延长、Seed、固定镜头、水印、MOV、返回尾帧不显示／不发送；UI不是声称与官方API功能完全相同。

选择2.5「视频编辑」后，将一段4～30秒视频节点连到当前生成节点，可另连最多30张图，不接参考音频。参数面板提供「输入视频实际时长（秒）」：留空时读取本次实际引用的来源视频节点`durationMs / 1000`，例如19050ms传19.05；也可手动填写小数，手动值优先，清空恢复自动。不会读取目标节点旧成片的时长，也不使用普通输出秒数代替。缺失／非有限数／非正数在上传和生成前阻止，不擅自取整、裁剪或补默认时长。

编辑提交`mode=videoEdit2video`、`duration=0`、`video_duration=19.05`（示例）、`aspect_ratio=adaptive`；`duration=0`只是编辑任务标记，`video_duration`才是输入视频长度，二者不能互相替代。输入保存到节点／配置节点及复制、重试参数中；自动值每次按当前引用的视频重新读取。隐藏普通输出时长、固定比例、帧模式和样片选项。其他模式按节点选择提交整数秒数或`-1`，不使用编辑的0，也不传`video_duration`。

编辑输入复用现有官方节点的滑条＋秒数输入布局：滑条范围按文档4～30秒，拖动精度0.001秒；数值输入保留实际小数，不静默取整／钳制。留空或点击「恢复自动读取」按实际来源读取，不用虚构的默认输出秒数顶替输入长度。滑条、输入框操作同一个seedanceVideoDuration字段，普通输出时长依旧独立。

若错误摘要仍只有duration=0而没有video_duration，说明最终脚本JSON漏写字段，不能把节点已填或前端params已有当作提交成功。模板现在明确写入body.video_duration并记录安全摘要；新版前端的脚本fetch入口额外检查显式seedance-series编辑JSON，缺失或无效就本地提示重新载入当前模型模板，不向平台发送。已保存脚本不会自动替换，必须在模型调用脚本里重新选择新版模板保存，或完整复制源码；可在脚本开头确认「编辑输入时长修订」注释。仅重启前端不覆盖浏览器已保存脚本。

## 素材与顺序

本地图片／视频／音频 → 既有新加坡COS → `reference_images`／`reference_videos`／`reference_audios`公网HTTPS URL。复用`https://sg-cos.maxai.art`所在COS配置，不另建Bucket、不向平台发送COS密钥或官方AK/SK。当前渠道完整COS优先，否则复用唯一一套完整配置；存在多套不同配置时，给当前渠道绑定COS或在脚本`COS_SOURCE_CHANNEL_ID`指定来源。

新文档允许直接HTTPS URL，因此无需再调用旧平台CreateAssetGroup／CreateAsset／GetAsset或官方真人私域库。保留数组顺序、重复项和提示词原文；帧模式显式传`frames2video`，其余普通模式由平台选择，不传字面量auto。使用本平台已有`asset_…`时原样传，不加`asset://`，其他站点的素材ID不能复用。文档另有`POST /v1/assets`文件上传，但本模板按已有COS流程使用URL，不新增第二次平台文件上传。

2.0最多9图／3视频／3音频，2.5最多30图／10视频／10音频、合计50。文件格式、尺寸、大小、时长与权利审核以新文档及上游校验为准；脚本不擅自转码、裁剪或绕过真人审核。新文档没有单列真人认证接口，不代表保证任何真人素材获准。

素材准备仍在浏览器运行，上传时保持网页打开；最终视频创建被后台接收后，网页关闭不影响后台等待。刷新不会重新执行脚本、上传或收费POST。

## 样片转正片

2.5样片固定480p，完成保存平台任务ID。点击「正式生成」先调用`POST /v1/final-conversions/{样片ID}/estimate`，显示预扣人民币金额及报价有效期；取消不创建正片。确认后只提交`{quote}`到`/v1/final-conversions/{样片ID}`，附唯一Idempotency-Key，不重发提示词、素材或旧draft_task字段。过期报价不提交，需要重新点击获取；受理不确定时查询原任务，禁止自动重新报价并创建。

普通任务查询`/v1/videos/{id}`，正片查询`/v1/final-videos/{id}`；后台每10秒查询，遵循更长Retry-After，生成中无本地截止时间。完成后从对应`/content`带平台Bearer下载，即使查询没有公开URL也能领取；跨域重定向不携带Key。失败读取error并返回节点。不把HTTP200等同生成成功。

本机与Docker按原策略在磁盘保存终态结果24小时、ACK不删除且不续期。刷新只读取结果，不重跑JS。容器／本机服务重启仍会中断正在执行的连接；已知ID保留，不自动重发收费请求。本更新未实现对所有重启中的任务自动续查。

## 费用与验证边界

用户已确认补齐输入时长后的2.5编辑恢复正常；以下排查记录是此前开发依据，不能据此宣称其他模型、样片转正片或完整计费均已验收。

### 编辑提交失败排查

脚本已增加跨类别MIME检查：若视频数组里实际收到image/png等图片文件，上传和创建前直接报出错配，不会把它重新归类或继续收费提交。正常视频节点以原文件内容和video MIME上传COS，并仅写入`reference_videos`；附加图片独立写入`reference_images`。

失败时脚本在上游说明后补充实际JSON的模型、模式、duration、video_duration、比例、分辨率、开关、各类素材数量及视频MIME。该摘要不包含Key、提示词、报价凭证或素材URL，不重新提交。网页保持打开时可看到新脚本追加的摘要；刷新恢复仍以后台已保存的上游错误和节点快照为准，不重新执行脚本补摘要。已安装旧版模板不会自动覆盖；替换为更新后的`web/src/services/api/seedance-series-script.js`。本次自动读取及手动输入需同步更新前端；代理透传JSON无需新增协议。这里只改共享源码，未构建、重启或发布镜像。

17项针对性模拟回归通过，包括节点分类→文件→COS上传体→脚本JSON、纯视频及附图编辑、自动读取小数秒／手动覆盖／更换来源、复制重试保存、无时长时零上传零提交、其他脚本隔离及安全摘要。用户确认的漏传`video_duration`已补齐；先前仅根据不完整文档认为请求已齐全的判断不再适用。模拟HTTP不等于真实收费生成验收，旧失败任务不会因补字段自动重试。

平台现在按实际视频Token结算，参考视频与分辨率会影响单价，预扣不等于最终消费。本地费用页仍按用户设置的分辨率、秒数／次数估算，成功保存后确认；未把文档Token报价擅自写入本地单价。编辑0和智能-1没有确定输出秒数，按秒估算保持未定价，不测量成片。报价请求与COS上传不记为视频生成。

已增加离线脚本／模型／后台查询下载和磁盘恢复模拟验证，未调用真实收费生成；浏览器视觉、平台权限、素材规格、实际结算及生成结果需用户验收。平台明确继续使用HTTP入口，不擅自改成HTTPS；Key与素材URL在代理到平台这一段没有HTTPS保护，可向平台询问加密接入方案，但不可把建议当成已提供的地址。
