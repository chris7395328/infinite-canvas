# @basketikun/canvas-proxy

Infinite Canvas 的本地转发代理。浏览器直连第三方 AI 接口时经常被 CORS 拦截，启动它之后，网页会把请求先发到本机，再由本机转发到目标地址。

普通代理路由不改写请求体、不校验 API Key。画布后台任务在Docker映射目录保存响应及完成结果，不记录请求密钥或请求体。

## 画布后台生成与24小时结果存储

当前fork启用本地代理后，原生画布生成请求交给 `/_tasks/<id>` 执行，包括OpenAI兼容视频、Gemini Veo／Omni、显式JSON脚本协议、旧魔芋原任务查询和下载。刷新／关闭网页后重新打开同一站点／浏览器／画布只查询原结果，不重新生成。网页及后台轮询统一10秒，上游更长Retry-After优先。查询暂时断连／5xx继续查询，不重新POST。未开启代理仍为前端执行，不能保证刷新恢复。

- Docker设置`CANVAS_TASK_DIR=/var/lib/infinite-canvas/tasks`并映射`./task-data`，结果流式写盘；不设应用层容量上限，也不再使用256 MiB载荷预算。真实剩余磁盘与进程内存仍可能不足。
- 结果完成后固定保留24小时，已领取也不删除、不续期；浏览器确认只用于浏览器侧保存流程。每分钟清理过期文件，超过24小时立即停止提供领取；代理停机期间不执行清理，启动时补清理。不要删除、改名或换掉映射目录。
- 请求体／鉴权头／API Key不落盘，只保存响应和任务状态、任务访问凭据哈希、上游任务ID。存储目录含用户生成内容及响应中的临时URL，请限制目录访问并避免放到公开Web目录；已加入Git/Docker构建排除。
- 已完成文件跨容器重启可领取。生成中不设本地截止时间，但重启会切断未完成上游连接：没有最终文件时标记结果不确定、保留已知上游ID，不能自动重发收费POST；同步请求无法凭空恢复。磁盘写入失败不会标记成功。升级前旧版RAM文件无法自动迁移，需先领取。
- 未设置CANVAS_TASK_DIR的本地代理仍使用RAM；领取后同样保留至24小时，但该模式重启会丢失结果。
- 需要同步更新app和proxy。后台文字完整生成后显示。任意自定义脚本不自动重跑；内置模板恢复只允许取回已提交POST，不为遗漏步骤补发请求。
- 任意自定义脚本的查询编排仍需逐个适配，不在服务端执行用户JavaScript。官方Seedance桥接由Docker等待上游，保留带草稿ID的JSON回执，视频文件仍由浏览器落库。
- 模型脚本优先；未配置时按渠道协议调用，OpenAI兼容视频默认 /videos 表单，不保证任意中转站接受。脚本变量 `model` 为实际所选ID（仅移除本地渠道前缀），不替换成文档示例名。已配置933脚本保持不变。
- JSON视频脚本可设置 `x-canvas-video-protocol: json-video`：POST /videos/generations、GET /videos/{id}，读取顶层／data任务及完成状态／video_url。旧 xing933 是同协议别名；该头由代理消费，不发往上游。其他路径／结构由脚本适配，任意脚本不会因刷新自动重跑。
- 普通转发仍按原方式流式透传。任务接口需要每个任务独立的随机访问凭据，不提供任务列表；应继续使用HTTPS和可信访问边界保护整个部署。

## 使用

```bash
npx @basketikun/canvas-proxy@latest
```

默认监听 `http://127.0.0.1:23210`。把这个地址填进 Infinite Canvas 的「配置 → 本地代理」，并打开开关即可。

带上 `@latest` 是因为 npx 会缓存已下载的版本，不加就可能一直运行旧版本。

可选参数：

```bash
npx @basketikun/canvas-proxy@latest --port 23210 --host 127.0.0.1
```

也支持 `PORT` / `HOST` 环境变量。

## 转发规则

把完整目标地址接在代理地址后面：

```
http://127.0.0.1:23210/https://api.openai.com/v1/models
        └─── 代理地址 ──┘└──────── 目标地址 ────────┘
```

请求方法、请求头（除 `host` 等逐跳头外）、请求体原样转发；响应状态码、响应头和响应体原样返回，并补上宽松的 CORS 头。SSE 流式响应按块透传，不做缓冲。

访问根路径 `/` 会返回代理版本信息，可用于连通性检测，不会记入转发日志。

## 转发日志

每转发一条请求就在终端打印一行，包含时间、方法、完整目标地址、上游状态码和耗时：

```
4:05:42 PM GET https://api.openai.com/v1/models -> 200 0.9s
4:05:43 PM POST https://api.openai.com/v1/images/generations -> 200 26.4s
4:05:45 PM GET https://api.example.com/v1/models -> failed (fetch failed) 1.6s
```

日志在收到上游响应头时打印，所以流式请求会立刻出现一行，而不是等整段响应结束。日志只输出到终端，不落盘，也不包含请求头和请求体，因此不会泄露 API Key。

## 安全提示

代理默认只监听 `127.0.0.1`，仅本机可访问。它会转发任何请求到任何地址，请不要用 `--host 0.0.0.0` 暴露到公网。API Key 依然由浏览器持有并随请求转发，处理期间会经过代理内存，不持久化到文件或日志。

## 环境要求

Node.js >= 18。
